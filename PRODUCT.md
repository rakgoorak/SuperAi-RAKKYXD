# SuperAi & RAKKYXD

## Platform
Windows desktop first, with a browser-accessible workspace UI. Existing Electron/React/TypeScript stack retained.

## Users and purpose
Thai-speaking user who wants to create software with several CLI agents and inspect websites in one easy-to-use workspace. Companion dictation app supplies Thai or English text to the workspace or a chosen Windows app.

## Confirmed requirements
BridgeMind-inspired workflow; original SuperAi & RAKKYXD branding. Thai interface. Real projects, terminals, conversation, assistant and browser Preview. Claude Code, Codex, Gemini CLI, OpenCode and Freebuff; Freebuff limited to one managed running session. No sample statuses or decorative inactive buttons. Separate SuperAi Voice & RAKKYXD application. Errors must be actionable. Accounts and microphone validation require actual user hardware/credentials.

## Approved direction
User approved the 2026-10-20 design draft and asked to proceed. Local Whisper transcription recommended in that approved design. No distribution pricing, cloud service or paid model is assumed.
