# บัญชี โมเดล และ Skills ในแชท

- หน้าเริ่มต้นแสดงสถานะบัญชีแยก Claude Code, Codex, Antigravity, OpenCode และ Freebuff ที่ติดตั้งแล้ว การพบ CLI และเครื่องหมายยืนยันของผู้ใช้ไม่ถือเป็นผลตรวจบัญชี
- Claude ใช้ `claude auth status` และ Codex ใช้ `codex login status` เพื่อตรวจสถานะในเครื่อง ข้อมูลบัญชีดิบและ credential ไม่ถูกส่งกลับไปแสดงใน UI
- กด **เข้าสู่ระบบใน Terminal** เพื่อเปิดขั้นตอนของ provider แล้วกลับแท็บแชทเดิมและกด **ตรวจบัญชีอีกครั้ง** แท็บล็อกอินเป็นแท็บชั่วคราว ไม่ถูกบันทึกกลับมาเป็นบทสนทนา
- OpenCode ตรวจรายการผู้ให้บริการได้ แต่รายการว่างไม่ได้หมายความว่าใช้ไม่ได้ เพราะบางโมเดลฟรีและบางการตั้งค่าใช้ credential จาก environment ข้อผิดพลาดของโมเดลหรือโควตาไม่ถูกเปลี่ยนเป็นข้อผิดพลาดล็อกอิน
- Antigravity และ Freebuff ยังไม่มีคำสั่งตรวจบัญชีที่ระบบนี้ยืนยันได้ จึงแสดงว่ายังตรวจบัญชีอัตโนมัติไม่ได้ และให้เปิด Terminal ของเครื่องมือนั้นแทน

## เลือกโมเดลตรงช่องพิมพ์

แชทของแต่ละ session มีช่อง Model และ Effort ใช้กับข้อความถัดไปและบันทึกเมื่อส่งสำเร็จที่ API หากล้างช่องจะกลับไปใช้ค่าเริ่มต้นของ CLI ส่วนโหมด Chat ที่ถามหลาย AI มีตัวเลือกของแต่ละ Main อยู่เหนือช่องพิมพ์ และใช้ค่าชุดเดียวกับหน้า “ตั้งค่า Chat”

## เรียก Skill

พิมพ์ `/skills` หรือกดปุ่ม `/skills` เพื่อดูรายการ แล้วเลือก skill และเติมงาน เช่น:

```text
/skill webapp-testing ตรวจหน้าเข้าสู่ระบบ
```

หรือใช้ `/ชื่อ-skill งานที่ต้องการ` สำหรับชื่อที่มีในรายการ ระบบค้นหา `SKILL.md` ในโปรเจกต์ โฟลเดอร์แม่ และตำแหน่งส่วนตัวของ provider รวมถึง skill ที่ติดตั้งผ่าน SuperAi รองรับโฟลเดอร์ skill ที่เป็น symlink ด้วย

Claude แสดง skill ของ plugin ที่ลงทะเบียนและเปิดใช้งานไว้ในเครื่องด้วย โดยใช้ชื่อ `plugin:skill` การเลือกจากรายการในแชทราย session จะแยก skill ชื่อซ้ำด้วย ID ส่วนการพิมพ์ชื่อเองเลือกตำแหน่งใกล้โปรเจกต์ก่อนตำแหน่งส่วนตัว

ระบบส่งคำสั่งให้ provider อ่านและทำตามไฟล์ skill พร้อมระบุตำแหน่งทรัพยากร ไม่เรียกสคริปต์หรือขยาย shell macro ในไฟล์ skill เอง สิทธิ์การใช้เครื่องมือยังขึ้นกับโหมดและ provider หากต้องใช้คำสั่งเฉพาะ TUI, skill ที่โหลดผ่านบริการภายนอก, plugin ที่ไม่มีไฟล์ในตำแหน่งที่รองรับ หรือพฤติกรรมเฉพาะของ CLI ให้สลับไปหน้า Terminal

ในโหมด Chat หลาย AI แต่ละตัวค้นหา skill ชื่อนั้นจากรายการของตนเอง หากไม่มีจะแสดงข้อผิดพลาดของตัวนั้น โหมดนี้อ่านไฟล์ได้ งานที่ต้องแก้ไฟล์ให้ใช้แชทในโหมด Code

Freebuff ยังคงใช้ผ่าน Terminal เท่านั้น จึงใช้ตัวเลือกและคำสั่งที่ Freebuff รองรับใน Terminal โดยตรง

## การตรวจสอบ

เทสต์ครอบคลุมบัญชีที่ยังไม่ล็อกอิน การลองใหม่หลังล็อกอิน การไม่บล็อกโมเดลฟรี การไม่สับสนข้อผิดพลาดโควตา การส่งและบันทึก Model/Effort การค้นหาและเลือก skill ชื่อซ้ำ และการหยุด CLI ที่ไม่ตอบกลับ

การทดสอบ UI ผ่าน Electron ยังต้องทำในเครื่องที่อนุญาตการเปิดพอร์ต localhost สภาพแวดล้อมตรวจสอบปัจจุบันปฏิเสธด้วย `listen EPERM`

อ้างอิงคำสั่งและตำแหน่งไฟล์: [OpenAI Docs](https://learn.chatgpt.com/docs/developer-commands), [Claude CLI](https://code.claude.com/docs/en/cli-reference), [Claude Skills](https://code.claude.com/docs/en/skills), [OpenCode CLI](https://opencode.ai/docs/cli/), [OpenCode Skills](https://opencode.ai/docs/skills/), [Antigravity authentication](https://www.antigravity.google/docs/install?tab=cli), [Antigravity Skills](https://www.antigravity.google/docs/skills).
