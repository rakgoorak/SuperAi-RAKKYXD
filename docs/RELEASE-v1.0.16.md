# SuperAi & RAKKYXD v1.0.16

## มีอะไรใหม่

- **เมนูคำสั่งลัด `/` (Slash Commands & Skills Autocomplete):** พิมพ์ `/` ในช่องข้อความเพื่อเปิดเมนูป๊อปอัปเลือก Skills และคำสั่งลัด มีระบบค้นหา คีย์ลัดนำทาง (ลูกศรขึ้น-ลง, Esc เพื่อปิด, Enter หรือ Tab เพื่อเติมคำสั่ง) ไม่ส่งข้อความทันที ช่วยให้พิมพ์คำสั่งต่อได้สะดวก
- **ย้ายแผงควบคุม Session Chat ลงช่องพิมพ์ด้านล่าง:** รวมการเลือก Model, Effort, สถานะบัญชี และ Skills ของ session ในโหมด Code ให้กระชับ สวยงาม และเปิดรายการ Model เหนือช่องพิมพ์อย่างถูกต้อง
- **จำการตั้งค่าแยกแต่ละ Session:** จดจำค่า Model และ Effort แยกราย session อย่างอิสระ และคงค่าเริ่มต้นของ CLI เมื่อสลับ session
- **ปรับแต่ง Layout ให้จอขนาดเล็กใช้งานได้เต็มประสิทธิภาพ:** ปรับขนาดช่องคำสั่งรวมและพื้นที่ทำงานให้อยู่ในสัดส่วนที่เหมาะสม ไม่ดัน Terminal จนล้นหน้าจอ (<= 104px ในโหมดคอมแพกต์)

รุ่นนี้เผยแพร่สำหรับ Windows x64: ตัวติดตั้ง Setup.exe และ ZIP portable พร้อม SHA-256 Checksums
