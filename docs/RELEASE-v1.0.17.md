# SuperAi & RAKKYXD v1.0.17

## มีอะไรใหม่

- **เรียกใช้ Slash Commands `/` ได้ทุกที่ในช่องพิมพ์:** รองรับการพิมพ์ `/` ได้ทั้งตอนเริ่มข้อความและต่อท้ายข้อความ (เช่น `ทำงานดีมาก /`) โดยป๊อปอัปเมนูจะแสดงคำสั่งและ Skills ที่เรียกใช้ได้ทันที และคงข้อความเดิมข้างหน้าไว้ ไม่ลบข้อความที่พิมพ์ไว้ก่อนหน้า
- **ปรับ UI ให้สะอาดแบบ Claude, ChatGPT และ Antigravity:** นำปุ่ม `/skills` และ `ยกเลิก skill` ออกจากแถบควบคุมด้านล่าง เพื่อให้ช่องพิมพ์เรียบหรูและกระชับ ควบคุมคำสั่งและเครื่องมือผ่านเมนู `/` ในช่องพิมพ์ได้ครบจบในที่เดียว
- **รองรับคำสั่งตรง `/<skill>`:** สามารถพิมพ์เรียกใช้ Skill ได้โดยตรง เช่น `/review` หรือ `/find-skills` โดยไม่ต้องพิมพ์ `/skill` นำหน้า
- **จัดการ Autocomplete ให้ราบรื่น:** ซ่อนข้อความจาง Ghost-text อัตโนมัติขณะกำลังเลือกคำสั่ง Slash เพื่อไม่ให้บดบังสายตา

รุ่นนี้เผยแพร่สำหรับ Windows x64: ตัวติดตั้ง Setup.exe และ ZIP portable พร้อม SHA-256 Checksums
