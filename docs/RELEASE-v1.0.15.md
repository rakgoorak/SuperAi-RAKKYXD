# SuperAi & RAKKYXD v1.0.15

## มีอะไรใหม่

- ย้าย Model, Effort, บัญชี และ Skills ของแชตแต่ละ session มาไว้ที่ช่องพิมพ์ด้านล่างในโหมด Code
- เมนูคำสั่งลัด `/` (Slash Commands) แสดงรายการคำสั่งและ Skills ที่เรียกใช้ได้ พร้อมคีย์ลัด ↑ ↓ และ Tab/Enter
- จำตัวเลือกแยกตาม session และแก้การเลือกค่าเริ่มต้น CLI ให้คงอยู่เมื่อสลับ session
- ล้างตัวเลือก skill หลังส่งข้อความสำเร็จให้ตรงกับหน้าจอ
- แก้สถานะการ์ด Agent สำหรับงานยกเลิก งานที่ข้าม และผู้ช่วยที่ไม่ได้รับงาน
- ปรับพื้นที่หน้าทีมสำหรับจอแล็ปท็อป ให้เห็นรายการงานและปุ่มรายละเอียดมากขึ้น พร้อมพับคำแนะนำขั้นตอนถัดไป

รุ่นนี้เผยแพร่สำหรับ Windows x64: ตัวติดตั้งและ ZIP portable พร้อม SHA-256
