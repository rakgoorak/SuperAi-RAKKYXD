# SuperAi & RAKKYXD v1.0.22

## มีอะไรใหม่

- รายการตัวเลือก (dropdown) เป็นสีมืดตามธีมแล้ว ไม่ขึ้นเป็นกล่องสีขาวบน Windows
- เก็บสีน้ำเงินที่หลงเหลือจากธีมเก่าในหน้าต่าง Skills แท็บ ป้าย และเส้นคั่น ให้เป็นโทนอุ่นเดียวกันทั้งแอป
- หน้าต่าง "เริ่มต้นใช้งาน" ใหม่: หัวบอกว่าเหลืออีกกี่ขั้น รายการขั้นตอนเดียวที่เลื่อนได้ชั้นเดียว คำอธิบายสั้นลง และเอาปุ่มเข้าสู่ระบบที่ซ้ำออก
- หน้าต่าง Skills เลื่อนได้ชั้นเดียว ปุ่ม "ดูไฟล์" และ "ติดตั้ง" ไม่ตัดบรรทัด
- ช่อง Effort ในทีม Agent และถามหลาย AI กว้างพอให้อ่านครบ และแสดง "อัลตรา" แทน ultra
- ช่องพิมพ์ไม่มีที่จับลากขยายที่มุมอีกแล้ว
- หน้าตั้งค่าแยก "เวอร์ชัน CLI" เป็นหมวดของตัวเอง

## การตรวจสอบ

- Production build, unit tests และ desktop smoke ทุกชุด (desktop, layout, usage overlay, reference, team, voice, conversation workspace, session controls)
