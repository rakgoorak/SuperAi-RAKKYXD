# SuperAi & RAKKYXD v1.0.13

## มีอะไรใหม่ใน v1.0.13

- **แก้เปิดโปรแกรมแล้วขึ้น "เปิด SuperAi & RAKKYXD ไม่สำเร็จ · ERR_ABORTED":** ถ้าหน้าโปรแกรมถูกโหลดใหม่ระหว่างที่ยังโหลดครั้งแรกไม่เสร็จ (เช่น กด Ctrl+R หรือปุ่มโหลดใหม่ตอนเปิดโปรแกรม) โปรแกรมเคยแจ้งว่าเปิดไม่สำเร็จแล้วปิดตัวเอง ทั้งที่หน้าโปรแกรมโหลดได้ปกติ ตอนนี้ทำงานต่อได้ตามปกติ
- **รุ่นนี้มีเฉพาะ Windows ก่อน:** ไฟล์สำหรับ macOS จะตามมาภายหลัง

## ใน v1.0.12

- **Claude Code ไม่พังเองอีก:** Claude Code อัปเดตตัวเองระหว่างเปิด session แล้ว npm รุ่นใหม่บล็อกขั้นตอนวางไฟล์ `claude.exe` ทำให้เปิดไม่ได้อีกครั้ง ตอนนี้ session ในแอปปิดการอัปเดตเองของ Claude Code และให้ระบบอัปเดต CLI ของแอปเป็นผู้อัปเดตแทน
- **ติดตั้ง Claude Code ใหม่ได้เมื่อติดตั้งไม่สมบูรณ์:** เดิมกด "ติดตั้ง Claude Code" แล้วขึ้น "เครื่องมือนี้ติดตั้งแล้ว" ทั้งที่เปิดไม่ได้ ตอนนี้ติดตั้งซ้ำทับให้
- **Skill บน Windows:** ที่อยู่ไฟล์ SKILL.md ที่ส่งให้ AI ถูกต้องแล้ว (เดิมมีเครื่องหมาย `\` ซ้อนสองตัว)
- **รุ่นนี้มีเฉพาะ Windows ก่อน:** ไฟล์สำหรับ macOS จะตามมาภายหลัง

## ใน v1.0.11

- **ยกระดับความปลอดภัยและป้องกันข้อมูลหลุด (Security Hardening):**
  - กรองและปกปิด Credential (API Keys, Bearer tokens, GitHub tokens) ใน Log Sanitizer อัตโนมัติ ป้องกันข้อมูลรั่วไหลลงดิสก์หรือบันทึกประวัติ พร้อมจำกัดสิทธิ์โฟลเดอร์ `0o700` และไฟล์ `0o600`
  - ตรวจสอบความปลอดภัย Localhost Server & WebSocket อย่างเข้มงวด ทั้ง Host, Origin และ Referer ป้องกัน DNS Rebinding และ CSRF พร้อมเพิ่ม Header ความปลอดภัย (`X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`)
  - ตรวจสอบ SHA-256 Checksum ของ PortableGit และไฟล์ติดตั้งภายนอกทุกครั้ง ปฏิเสธการรัน Binary แปลกปลอมหรือไม่ผ่านการตรวจสอบ
  - รองรับระบบ Authenticode Code Signing บน Windows และ Apple Developer ID Hardened Runtime + Notarization บน macOS
- **หน้าเริ่มต้นใช้งานและ Mission Control Setup โฉมใหม่:**
  - เพิ่มแถบสถานะความพร้อมระบบแบบเรียลไทม์ (% Ready)
  - ปุ่ม "ติดตั้งสิ่งที่ขาดอัตโนมัติ" (One-Click Auto-Setup) ดาวน์โหลดและติดตั้ง Git, Node.js 22 และ CLI ที่จำเป็นได้ในคลิกเดียว
  - จัดระเบียบ Checklist ตรวจสอบความพร้อมของระบบเป็นหมวดหมู่ชัดเจน พร้อม Badge แสดงสถานะ
- **Studio Launch Hub ดีไซน์ Cyber-Obsidian:**
  - ปรับโฉมหน้าแรกเมื่อเปิดห้องทำงานใหม่ สวยงาม ทันสมัย ใช้งานง่าย
  - 3 โหมดทำงานหลัก: Coding Studio, Multi-Agent Team, และ Chat & Plan
  - แถบสถานะผู้ช่วย AI (Claude Code, OpenAI Codex, OpenCode, Google Antigravity) ตรวจสอบความพร้อมและเข้าถึงได้ทันที
  - Quick-starter Prompt Chips สำหรับเริ่มต้นโปรเจกต์ ตรวจสอบความปลอดภัย หรือแก้บักในคลิกเดียว
- **ปรับปรุงเสถียรภาพชุดทดสอบและสคริปต์ Build:**
  - ปรับปรุงสคริปต์ทดสอบให้รองรับ Node test runner ได้สมบูรณ์ ผ่านการทดสอบ 139/139 ทุกโมดูล

## ใน v1.0.10

- **หน้าแชตแบบ Claude สำหรับ Claude Code, Codex, Antigravity และ OpenCode:** session ใหม่เปิดเป็นหน้าแชต ข้อความเป็นบับเบิล คำตอบแสดง Markdown (ตาราง โค้ด ลิงก์) ภาษาไทยไม่เพี้ยน งานที่ AI ทำแสดงเป็นการ์ดย่อพับได้ เช่น "รัน 2 คำสั่ง · อ่าน 1 ไฟล์" กดดูคำสั่งและผลลัพธ์ได้ มีช่องพิมพ์ของตัวเอง (Enter ส่ง, Shift+Enter ขึ้นบรรทัดใหม่) แนบรูป/PDF ได้ และมีปุ่มหยุด
- **แชตกับ Terminal เป็นบทสนทนาเดียวกัน:** ปุ่ม **แชต | Terminal** มุมขวาบน กด Terminal จะเปิด TUI ของ CLI ต่อจากบทสนทนาในแชต กลับมาแชตก็คุยต่อจากที่ทำใน Terminal (Freebuff ยังใช้ได้เฉพาะ Terminal)
- **ปิดโปรแกรมแล้ว session ยังอยู่:** session และประวัติแชตถูกเก็บไว้ เปิดโปรแกรมใหม่ก็ทำงานต่อได้เลย ไม่ต้องเปิด session ใหม่ทุกครั้ง หน้าแชตไม่เปิด CLI ค้างไว้ จึงไม่กินเครื่อง
- **ลบ session ได้:** ปุ่มถังขยะที่รายการ session แถบซ้าย หรือปุ่ม X บนแท็บ (ถามยืนยันก่อน และลบประวัติแชตด้วย)
- **แก้กดปิด session แล้วหน้าต่างไม่หาย:** เมื่อ CLI ปิดตัวเองไปก่อนแล้ว การกด "ปิด" เคยขึ้น "ปิด process ลูกไม่สำเร็จ" ซ้ำไม่จบ ตอนนี้ปิดได้ทันที
- **รุ่นนี้มีเฉพาะ Windows ก่อน:** ไฟล์สำหรับ macOS จะตามมาภายหลัง
- **แก้ Claude Code ที่ติดตั้งแล้วเปิดไม่ได้:** npm รุ่นใหม่บล็อกสคริปต์ติดตั้งของ Claude Code ทำให้ไม่มีไฟล์ `claude.exe` ตัวจริง ตอนนี้แอปอนุญาตสคริปต์ของ CLI ที่ติดตั้งให้ และถ้าพบการติดตั้งที่ไม่สมบูรณ์จะให้ติดตั้งใหม่แทนการขึ้นว่าพร้อมใช้

## ใน v1.0.9

- **ปุ่ม "อ่านแบบข้อความ" เห็นชัดขึ้น:** ย้ายปุ่มไปไว้มุมขวาบนของแท็บ CLI และเปลี่ยนเป็นสีฟ้าเด่นชัด (เดิมอยู่มุมขวาล่าง สีจางจนกลืนกับพื้นหลังและทับแถวสถานะของ CLI เช่น Codex) กดเพื่ออ่านผลลัพธ์เป็นตัวหนังสือปกติ สระและวรรณยุกต์ไม่เพี้ยน กด **Esc** หรือ **กลับไปพิมพ์** เพื่อกลับไป terminal
- **ทดสอบ Release บน CI ไม่ค้างเงียบ:** ชุดทดสอบ smoke ของแอปบอกขั้นตอนที่ค้าง และปิดแอปได้เสมอแม้ process ไม่ยอมปิดเอง

## ใน v1.0.3

- **แจ้งอัปเดตเองทันที:** โปรแกรมตรวจเวอร์ชันใหม่ตอนเปิดและทุก 30 นาที แล้วดาวน์โหลดไว้เบื้องหลัง มีการ์ดขึ้นมุมล่างขวาให้กด **อัปเดตตอนนี้** หรือ **ไว้ทีหลัง** ส่วนอัปเดตที่จำเป็นจะติดตั้งให้เองก่อนใช้งานต่อ

- **ตรวจเวอร์ชันของ CLI:** การตั้งค่า → เวอร์ชัน CLI บอกว่า Claude Code, Codex, Antigravity และ OpenCode ตัวไหนมีเวอร์ชันใหม่ แล้วกดอัปเดตได้ในโปรแกรม ตอนเปิดแท็บก็จะเตือนถ้า CLI ตัวนั้นเก่า
- **แท็บที่จบการทำงาน:** ถ้า CLI อัปเดตตัวเองแล้วปิดไป โปรแกรมจะเปิดใหม่ให้เอง ถ้าจบปกติจะปิดแท็บให้ ถ้ามีข้อผิดพลาดหรืออัปเดตไม่สำเร็จ แท็บจะค้างไว้ให้อ่านว่าเกิดอะไรขึ้น
- **แก้ Codex และ Freebuff:** คำสั่งที่พิมพ์จากช่องรวมส่งเข้าไปได้แล้ว ไม่ค้างอยู่ในช่องพิมพ์
- **แก้ Codex บน Mac ขึ้น “duplicate key” ใน config.toml:** ไม่เขียนซ้ำอีก และซ่อมไฟล์ที่เสียไปแล้วให้เองตอนเปิดโปรแกรม

## ความสามารถหลัก

ใช้ Claude, ChatGPT (Codex), Antigravity, OpenCode และ Freebuff ในโปรแกรมเดียว ไม่ต้องเปิดหลายโปรแกรมแล้วสลับไปมา

- **3 โหมด**
  - **Agent:** เลือก Main 1 ตัวกับ Sub-agent 1–6 ตัว Main วางแผนและแจกงาน Sub-agent ทำพร้อมกัน และเห็นว่าแต่ละตัวกำลังทำอะไร
  - **Code:** เปิด CLI หลายแท็บในหน้าต่างเดียว
  - **Chat:** ถามคำถามเดียวกับ AI หลายตัว แล้วให้ผู้สรุปรวมผลและบอกว่าใครแนะนำอะไร
- **เลือก model และ effort ได้ทุกที่** ตั้งค่าเริ่มต้นของแต่ละผู้ให้บริการได้ตั้งแต่เปิดโปรแกรมครั้งแรก
