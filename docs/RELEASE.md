# SuperAi & RAKKYXD v1.0.18

## มีอะไรใหม่ (Claude Desktop Minimal UI Redesign)

- **ดีไซน์โทนสี Warm Charcoal & Soft Ivory สไตล์ Claude Desktop:** เปลี่ยนโทนสีจากสีน้ำเงินไซเบอร์แบบเดิม เป็นโทนสีดำอุ่น (Warm Minimal Dark `#181816`, `#1f1f1d`) พร้อมตัวหนังสือสีงาช้างอ่อนที่สบายตา และไฮไลต์ด้วยสี Terracotta (`#d97757`)
- **กรอบโลโก้ SR Frosted Glass Badge:** ออกแบบตรายี่ห้อ SR ให้ครอบด้วยกรอบกระจกใสโปร่งแสงกึ่งทึบ (Translucent Glass Pill) หรูหราและกลมกลืนกับพื้นหลังโทนอุ่น ไม่ขัดตา
- **Floating Capsule Composer:** ปรับช่องพิมพ์คำสั่งด้านล่างเป็นทรงแคปซูลมนลอยตัว (Floating Island Capsule, border-radius 18px) กึ่งกลางหน้าจอ พร้อมแถบเลือก Model / Effort แบบมินิมอล และปุ่มส่งสีส้ม Terracotta
- **การจัดวางบทสนทนาและฟอนต์อ่านง่ายระดับพรีเมียม:** ปรับคอลัมน์แชทกว้าง 780px ตามมาตรฐาน Claude พร้อมกล่องข้อความผู้ใช้ทรงมนขวาสุด และการแสดงผล Markdown, ตาราง, และ Codeblocks พื้นหลังหินผิวด้านที่อ่านง่าย สบายตา
- **คงความเข้ากันได้กับการทำงาน Terminal เต็มรูปแบบ:** โหมดเทอร์มินัลคำสั่งปกติยังคงความกะทัดรัด (ความสูงไม่เกิน 104px) เพื่อให้พื้นที่การเขียนโค้ดและดูเทอร์มินัลกว้างขวางที่สุด

รุ่นนี้เผยแพร่สำหรับ Windows x64: ตัวติดตั้ง Setup.exe และ ZIP portable พร้อม SHA-256 Checksums

# SuperAi & RAKKYXD v1.0.17

## มีอะไรใหม่

- **เรียกใช้ Slash Commands `/` ได้ทุกที่ในช่องพิมพ์:** รองรับการพิมพ์ `/` ได้ทั้งตอนเริ่มข้อความและต่อท้ายข้อความ (เช่น `ทำงานดีมาก /`) โดยป๊อปอัปเมนูจะแสดงคำสั่งและ Skills ที่เรียกใช้ได้ทันที และคงข้อความเดิมข้างหน้าไว้ ไม่ลบข้อความที่พิมพ์ไว้ก่อนหน้า
- **ปรับ UI ให้สะอาดแบบ Claude, ChatGPT และ Antigravity:** นำปุ่ม `/skills` และ `ยกเลิก skill` ออกจากแถบควบคุมด้านล่าง เพื่อให้ช่องพิมพ์เรียบหรูและกระชับ ควบคุมคำสั่งและเครื่องมือผ่านเมนู `/` ในช่องพิมพ์ได้ครบจบในที่เดียว
- **รองรับคำสั่งตรง `/<skill>`:** สามารถพิมพ์เรียกใช้ Skill ได้โดยตรง เช่น `/review` หรือ `/find-skills` โดยไม่ต้องพิมพ์ `/skill` นำหน้า
- **จัดการ Autocomplete ให้ราบรื่น:** ซ่อนข้อความจาง Ghost-text อัตโนมัติขณะกำลังเลือกคำสั่ง Slash เพื่อไม่ให้บดบังสายตา

รุ่นนี้เผยแพร่สำหรับ Windows x64: ตัวติดตั้ง Setup.exe และ ZIP portable พร้อม SHA-256 Checksums

- **เมนูคำสั่งลัด `/` (Slash Commands & Skills Autocomplete):** พิมพ์ `/` ในช่องข้อความเพื่อเปิดเมนูป๊อปอัปเลือก Skills และคำสั่งลัด มีระบบค้นหา คีย์ลัดนำทาง (ลูกศรขึ้น-ลง, Esc เพื่อปิด, Enter หรือ Tab เพื่อเติมคำสั่ง) ไม่ส่งข้อความทันที ช่วยให้พิมพ์คำสั่งต่อได้สะดวก

- **ปรับแต่ง Layout ให้จอขนาดเล็กใช้งานได้เต็มประสิทธิภาพ:** ปรับขนาดช่องคำสั่งรวมและพื้นที่ทำงานให้อยู่ในสัดส่วนที่เหมาะสม ไม่ดัน Terminal จนล้นหน้าจอ (<= 104px ในโหมดคอมแพกต์)

รุ่นนี้เผยแพร่สำหรับ Windows x64: ตัวติดตั้ง Setup.exe และ ZIP portable พร้อม SHA-256 Checksums

# SuperAi & RAKKYXD v1.0.14

## มีอะไรใหม่ใน v1.0.14

## ใน v1.0.11

- **ยกระดับความปลอดภัยและป้องกันข้อมูลหลุด (Security Hardening):**
  - กรองและปกปิด Credential (API Keys, Bearer tokens, GitHub tokens) ใน Log Sanitizer อัตโนมัติ ป้องกันข้อมูลรั่วไหลลงดิสก์หรือบันทึกประวัติ พร้อมจำกัดสิทธิ์โฟลเดอร์ `0o700` และไฟล์ `0o600`
  - ตรวจสอบความปลอดภัย Localhost Server & WebSocket อย่างเข้มงวด ทั้ง Host, Origin และ Referer ป้องกัน DNS Rebinding และ CSRF พร้อมเพิ่ม Header ความปลอดภัย (`X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`)
  - ตรวจสอบ SHA-256 Checksum ของ PortableGit และไฟล์ติดตั้งภายนอกทุกครั้ง ปฏิเสธการรัน Binary แปลกปลอมหรือไม่ผ่านการตรวจสอบ
  - รองรับระบบ Authenticode Code Signing บน Windows และ Apple Developer ID Hardened Runtime + Notarization บน macOS
- **หน้าเริ่มต้นใช้งานและ Mission Control Setup โฉมใหม่:**
  - เพิ่มแถบสถานะความพร้อมระบบแบบเรียลไทม์ (% Ready)
  - ปุ่ม "ติดตั้งสิ่งที่ขาดอัตโนมัติ" (One-Click Auto-Setup) ดาวน์โหลดและติดตั้ง Git, Node.js 22 และ CLI ที่จำเป็นได้ในคลิกเดียว

  - 3 โหมดทำงานหลัก: Coding Studio, Multi-Agent Team, และ Chat & Plan

- **ปรับปรุงปุ่มแสดงสถานะเวอร์ชันที่แถบซ้ายล่าง:** เปลี่ยนไอคอนเป็นติ๊กถูกและแสดงข้อความ "เวอร์ชันล่าสุดแล้ว" เมื่อตัวแอปตรวจพบว่าเป็นเวอร์ชันล่าสุด เพื่อป้องกันความเข้าใจผิดว่ามีอัปเดตค้างอยู่
- **ปรับปรุงความเสถียรของชุดทดสอบ Release บน CI:** เพิ่มการปิด process อย่างชัดเจนในชุดทดสอบ release-smoke เพื่อให้กระบวนการ build & release อัตโนมัติทำงานราบรื่น

## ใน v1.0.7

- **ภาษาไทยในแท็บ CLI ไม่เพี้ยน:** สระบนและวรรณยุกต์ไม่ลอยหรือหลุดตำแหน่งแล้ว ตัวอักษรเรียงตรงคอลัมน์ (เดิมโปรแกรมวัดความกว้างตัวอักษรก่อนฟอนต์ภาษาไทยโหลดเสร็จ) ตัวอักษรไทยยังห่างกันเล็กน้อยตามช่องตารางของ terminal ซึ่งเป็นธรรมชาติของ terminal
- **โหมดอ่านแบบข้อความ:** กดปุ่ม **อ่านแบบข้อความ** มุมขวาล่างของแท็บ CLI เพื่ออ่านผลลัพธ์เป็นตัวหนังสือปกติเหมือนใน Claude สระและวรรณยุกต์ถูกต้อง เลื่อนอ่านและคัดลอกได้ ข้อความอัปเดตตาม CLI ระหว่างที่เปิดอยู่ กด **Esc** หรือ **กลับไปพิมพ์** เพื่อกลับไปพิมพ์ใน terminal (CLI ทำงานต่อตลอด ไม่ต้องเริ่มใหม่)

## ใน v1.0.6

- **ปรับปรุงเสถียรภาพของพอร์ตการทดสอบฝั่งเซิร์ฟเวอร์:** ให้ใช้ dynamic port ป้องกันพอร์ตชนกันขณะรัน integration test

## ใน v1.0.3

- **แจ้งอัปเดตเองทันที:** โปรแกรมตรวจเวอร์ชันใหม่ตอนเปิดและทุก 30 นาที แล้วดาวน์โหลดไว้เบื้องหลัง มีการ์ดขึ้นมุมล่างขวาให้กด **อัปเดตตอนนี้** หรือ **ไว้ทีหลัง** ส่วนอัปเดตที่จำเป็นจะติดตั้งให้เองก่อนใช้งานต่อ
- **อัปเดตแล้วงานไม่หาย:** ระบบรอให้ CLI ที่กำลังตอบหรืองาน Agent/Chat เสร็จก่อนจึงติดตั้ง แล้วเปิดแท็บเดิมกลับมาคุยต่อจากบทสนทนาเดิม ข้อความที่พิมพ์ค้างไว้ก็ยังอยู่
- **ตรวจเวอร์ชันของ CLI:** การตั้งค่า → เวอร์ชัน CLI บอกว่า Claude Code, Codex, Antigravity และ OpenCode ตัวไหนมีเวอร์ชันใหม่ แล้วกดอัปเดตได้ในโปรแกรม ตอนเปิดแท็บก็จะเตือนถ้า CLI ตัวนั้นเก่า
- **แท็บที่จบการทำงาน:** ถ้า CLI อัปเดตตัวเองแล้วปิดไป โปรแกรมจะเปิดใหม่ให้เอง ถ้าจบปกติจะปิดแท็บให้ ถ้ามีข้อผิดพลาดหรืออัปเดตไม่สำเร็จ แท็บจะค้างไว้ให้อ่านว่าเกิดอะไรขึ้น
- **แก้ Codex และ Freebuff:** คำสั่งที่พิมพ์จากช่องรวมส่งเข้าไปได้แล้ว ไม่ค้างอยู่ในช่องพิมพ์
- **แก้ Codex บน Mac ขึ้น “duplicate key” ใน config.toml:** ไม่เขียนซ้ำอีก และซ่อมไฟล์ที่เสียไปแล้วให้เองตอนเปิดโปรแกรม
- **ตัวอักษรใน terminal ไม่ซ้อนกัน:** ขยายขนาด เพิ่มระยะบรรทัด และใช้ฟอนต์ไทย สระและวรรณยุกต์จึงไม่ทับกัน
- ปุ่ม Usage แสดงแค่ชื่อปุ่ม กดแล้วค่อยดูโควตาของแต่ละตัว และไม่ตรวจเบื้องหลังจึงเบาเครื่องขึ้น
- เอากล่องชื่อบัญชีที่มุมล่างซ้ายออก

## ใน v1.0.2

- ปุ่ม Usage (มุมขวาบน) ดูโควตาที่เหลือของแต่ละผู้ให้บริการในที่เดียว (มาใน v1.0.1)

ผู้ที่ใช้ v1.0.2 หรือเก่ากว่า กดปุ่ม **อัปเดตโปรแกรม** ที่แถบซ้ายได้เลย ตั้งแต่ v1.0.3 เป็นต้นไปโปรแกรมจะแจ้งอัปเดตให้เอง

## ความสามารถหลัก

ใช้ Claude, ChatGPT (Codex), Antigravity, OpenCode และ Freebuff ในโปรแกรมเดียว ไม่ต้องเปิดหลายโปรแกรมแล้วสลับไปมา

- **3 โหมด**
  - **Agent:** เลือก Main 1 ตัวกับ Sub-agent 1–6 ตัว Main วางแผนและแจกงาน Sub-agent ทำพร้อมกัน และเห็นว่าแต่ละตัวกำลังทำอะไร
  - **Code:** เปิด CLI หลายแท็บในหน้าต่างเดียว
  - **Chat:** ถามคำถามเดียวกับ AI หลายตัว แล้วให้ผู้สรุปรวมผลและบอกว่าใครแนะนำอะไร
- **เลือก model และ effort ได้ทุกที่** ตั้งค่าเริ่มต้นของแต่ละผู้ให้บริการได้ตั้งแต่เปิดโปรแกรมครั้งแรก
- **Skills:** AI เสนอ skill ที่จำเป็นต่อโปรเจกต์ จากแหล่งทางการของ Anthropic และ OpenAI และติดตั้งเมื่อคุณกดยืนยันเท่านั้น
- **อัปเดตในโปรแกรม:** แจ้งเวอร์ชันใหม่ให้เอง ติดตั้งทับโดยไม่ต้องลบแล้วติดตั้งใหม่ ตรวจไฟล์ด้วย SHA-256 ก่อนติดตั้ง และเปิดงานเดิมกลับมาหลังอัปเดต
- **ปุ่ม Usage:** ดูโควตาที่เหลือของทุกผู้ให้บริการ
- **ตัวติดตั้งในคลิกเดียว:** Windows ใช้ `SuperAi-RAKKYXD-Setup.exe` เลือกโฟลเดอร์และสร้างทางลัดบนเดสก์ท็อปได้ ส่วน Mac ใช้ไฟล์ `.dmg` ลากไปที่ Applications
- โลโก้ SR และสีของโปรแกรมตามแบรนด์
- หน้าเริ่มต้นใช้งานที่ติดตั้ง Node.js, Git และ CLI ให้ได้, พูดเพื่อพิมพ์ภาษาไทยบนเครื่อง, แนบรูปและ PDF, และ Browser Preview

## เลือกดาวน์โหลด

- Windows 10/11: `SuperAi-RAKKYXD-Setup.exe` เปิดแล้วทำตามขั้นตอน เลือกโฟลเดอร์ แล้วเลือกสร้างทางลัดบนเดสก์ท็อปได้ที่หน้าสุดท้าย
- Mac Apple Silicon: `SuperAi-RAKKYXD-macos-arm64.dmg` เปิดแล้วลากโปรแกรมไปที่ Applications
- Mac Intel: `SuperAi-RAKKYXD-macos-x64.dmg`
- แบบ portable (ไม่ติดตั้ง): ไฟล์ `.zip` ของแต่ละเครื่อง

ไฟล์ `.sha256` ใช้ตรวจความถูกต้องของ ZIP รุ่นนี้ยังไม่มีลายเซ็นผู้พัฒนาของ Windows หรือ Apple notarization

## ข้อควรรู้

- เก็บโปรแกรมไว้ในโฟลเดอร์ที่คุณเขียนได้ (เช่น Documents หรือ Applications) เพื่อให้ปุ่มอัปเดตติดตั้งทับได้
- CLI ต้องเข้าสู่ระบบด้วยบัญชีของคุณเอง ค่าใช้จ่ายและโควตาขึ้นกับผู้ให้บริการ บางรุ่นอาจใช้กับแพ็กเกจของบัญชีคุณไม่ได้
- Freebuff ใช้ได้เฉพาะโหมด Code
