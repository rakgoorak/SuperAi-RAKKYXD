# SuperAi & RAKKYXD v1.0.20

## มีอะไรใหม่

- กดลิงก์ในคำตอบ AI เพื่อเปิดใน Preview ได้แล้ว รวม URL ที่พิมพ์เป็นข้อความธรรมดา
- เปิดรูปภาพ PDF และไฟล์ข้อความในโปรเจกต์ในแผง Preview ได้ รองรับที่อยู่ไฟล์ Windows ช่องว่าง และลิงก์ไปยังบรรทัดของโค้ด พร้อมปุ่มโหลดไฟล์ใหม่และดาวน์โหลดภาพ/PDF
- แสดงคำแนะนำเมื่อไฟล์หายหรือเปิดไม่ได้ โดยไฟล์ Preview ต้องอยู่ในโปรเจกต์ที่เลือก
- เปลี่ยนข้อความเติมด้วย Tab เป็นปุ่ม “ทำต่อจากคำตอบนี้” หลัง AI ตอบเสร็จ กดเพื่อร่างข้อความให้ตรวจเองก่อนส่ง
- เปลี่ยนปุ่มท้ายคำตอบเป็นไอคอนคัดลอก สร้างคำตอบใหม่ และเมนูตัวเลือก แยกดูไฟล์ที่เปลี่ยนออกจาก Preview พร้อมป้องกันการกดสร้างคำตอบซ้ำระหว่างรอเซิร์ฟเวอร์
- จำกัดขนาดเมนู `/` ให้ค้นหาและเลื่อนรายการด้านในได้ โดยไม่บังช่องพิมพ์
- จัดหน้าตา Code, Agent, Chat, Sidebar, Settings และ Preview ให้ใช้ระบบเดียวกัน พร้อมแก้การย่อพื้นที่สนทนาเมื่อเปิด Preview
- แก้ตัวจับเวลาที่เคยตัดงานเมื่อครบ 10 นาทีแม้ CLI ยังทำงาน เปลี่ยนเป็นวัดช่วงที่ไม่มีข้อมูลใหม่ พร้อมแยกข้อความเริ่มงานไม่สำเร็จและงานเงียบไป และไม่แสดงเครื่องมือที่ถูกตัดกลางคันว่าเสร็จแล้ว

## ขอบเขต

- เว็บไซต์ใช้ Chromium ภายในแอป Electron; โหมดเว็บใช้ iframe และมีปุ่มเปิดภายนอกเมื่อเว็บไซต์ไม่ยอมให้ฝัง
- Preview แสดงรูปภาพ/PDF ไม่เกิน 20 MB และข้อความไม่เกิน 512 KB; HTML แสดงเป็นข้อความและไม่รันสคริปต์
- ลิงก์ไปยังไฟล์นอกโปรเจกต์หรือผ่าน symlink ออกนอกโปรเจกต์จะไม่ถูกเปิด
- ยังใช้บัญชีและโควตาของ CLI แต่ละตัวตามเดิม

## การตรวจสอบ

- Production build ของ Core, Studio, Client และ Desktop
- ชุดทดสอบ Preview links, path containment, source line references และข้อผิดพลาดของไฟล์
- Browser renderer smoke ของการเปิดภาพ/PDF/ข้อความ/URL พร้อมตรวจคำแนะนำท้ายคำตอบ การเลือก session เมนู `/` และการย่อพื้นที่เมื่อเปิด Preview

รายละเอียดผลตรวจและข้อจำกัดของสภาพแวดล้อมทดสอบอยู่ใน `docs/superpowers/validation-2026-10-24-preview-links.md`
