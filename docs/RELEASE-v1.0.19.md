# SuperAi & RAKKYXD v1.0.19

## มีอะไรใหม่

- ปรับหน้าต่างทำงาน ช่องพิมพ์ และ Dialog ให้เรียบง่ายขึ้นด้วยโทนสีเข้มอุ่น แถบเลือก Model / Effort ที่กะทัดรัด และเมนูบัญชี AI ที่ไม่แย่งพื้นที่เขียน
- เพิ่มแก้ไขข้อความกลับเข้าช่องพิมพ์และลองส่งใหม่ โดย Code เก็บ Model, Effort, Skill และไฟล์แนบของข้อความใหม่ ส่วน Agent / Chat ใช้ค่าทีมและสิทธิ์เดิม พร้อมคำแนะนำเมื่อบัญชี โควตา หรือเครือข่ายมีปัญหา
- กลับมาทำงานต่อได้ด้วยการจำ Session ที่เลือก Model / Effort และตำแหน่งเลื่อน เพิ่มค้นหาประวัติจากโปรเจกต์ที่ลงทะเบียนและค้นหาภายในบทสนทนา
- เพิ่มหน้าต่างดูไฟล์ที่เปลี่ยนและ Git diff รวมไฟล์ใหม่ พร้อมเปิด Preview จากหน้าผลลัพธ์ รายการแสดงการเปลี่ยนแปลงปัจจุบันของทั้งโปรเจกต์ รวมงานที่ผู้ใช้แก้เอง

## ขอบเขตการใช้งาน

- การแก้ไขข้อความจะนำข้อความกลับเข้าช่องพิมพ์ให้ตรวจทาน และต้องแนบไฟล์ใหม่หากต้องการส่งไฟล์ไปด้วย
- ข้อความ Code เก่าที่มีไฟล์แนบแต่ไม่มีข้อมูลคำขอต้นฉบับจะไม่เปิดให้ลองส่งใหม่
- หน้าต่างดูการเปลี่ยนแปลงอ่านอย่างเดียว ต้องเป็นโปรเจกต์ Git และจำกัดขนาดไฟล์ 256 KB; ปุ่ม Preview เปิดเบราว์เซอร์เดิมโดยไม่เริ่มเซิร์ฟเวอร์ให้

## การตรวจสอบ

- Production build และชุดทดสอบอัตโนมัติ
- Desktop smoke, Code composer / session recovery และ Agent / Chat flow พร้อมประวัติและ Git diff
- ทดสอบตัวโปรแกรม Windows ที่แพ็กแล้วก่อนเผยแพร่

รุ่นนี้เผยแพร่สำหรับ Windows x64: ตัวติดตั้ง Setup.exe และ ZIP portable พร้อม SHA-256 checksums
