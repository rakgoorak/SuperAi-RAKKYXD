# เปรียบเทียบ SuperAi กับ CLI จริง

การทดลองนี้เรียก provider จริงและใช้โควตาของบัญชี ให้รันเมื่อ CLI พร้อม ลงชื่อเข้าใช้แล้ว และระบบอนุญาตให้ CLI เปิดโปรเซส เชื่อมต่อเครือข่าย และเขียนไฟล์ session ของตัวเองได้

1. สร้างโฟลเดอร์ทดลองว่าง ไม่มีไฟล์กฎหรือไฟล์ปักหมุด ปิด instructions และใช้บทสนทนาใหม่ทุกครั้ง บันทึกเวอร์ชัน CLI รุ่นโมเดล effort และวันที่ทดลอง
2. ใช้คำขอเดียวกันทุกครั้ง: `ตอบเป็นภาษาไทยสั้น ๆ: Git branch คืออะไร และมีประโยชน์อย่างไร 2 ข้อ` เลือกสิทธิ์อ่านอย่างเดียวและไม่แนบไฟล์
3. สำหรับแต่ละ provider ทดลอง CLI โดยตรงก่อน จากนั้นใช้ SuperAi ใน Code แบบแชตกับ provider เดียวกัน ปิดบริบทที่ SuperAi เพิ่ม และใช้รุ่น effort กับสิทธิ์เท่ากัน บันทึก input, cache read, cache write และ output ตามที่แต่ละ CLI รายงาน รวมทั้งคำตอบและเวลา ไม่แทนค่าที่ไม่มีข้อมูลด้วยศูนย์
4. ทดลอง Chat หนึ่งตัวโดยไม่มีผู้สรุป และ Agent หนึ่ง Main กับหนึ่ง Sub-agent จาก provider เดียวกัน ดู `Token ตามขั้นตอน` แล้วบันทึกทุกขั้นตอน รวมทั้งขั้นตอนที่ไม่มีข้อมูล โหมดทีมเพิ่มคำสั่งและอาจเรียกเครื่องมือหรือโมเดลหลายครั้ง จึงไม่ใช่การเปรียบเทียบคำขอที่เหมือนกันทุกประการ
5. ทำซ้ำหลายรอบและสลับลำดับการทดลอง เพราะ cache ประวัติ session และความไม่แน่นอนของโมเดลมีผล ห้ามนำ cached input ไปบวกซ้ำกับ input ที่ provider ระบุว่ารวม cache แล้ว

Freebuff มีเฉพาะมุมมอง terminal ในแอปนี้ ส่วนข้อมูล usage ของ Antigravity และ OpenCode ในโหมดทีมยังไม่ถูกเก็บในรูปแบบที่ตรวจสอบได้ ให้บันทึกว่าไม่มีข้อมูล ห้ามใช้ตัวนับจากความยาวข้อความแทน token จริง อย่าแนบ credential หรือ log ที่มีข้อมูลส่วนตัวในรายงาน
